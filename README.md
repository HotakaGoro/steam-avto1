# Steam-avto

Автоматизированный бот для управления друзьями в Steam с адаптивной оптимизацией производительности.

## Возможности

### Основные функции
- ✅ Автоматический приём заявок в друзья (мин. задержка 7 сек)
- ✅ Автоматическая отправка сообщений (мин. задержка 10 сек)
- ✅ Приглашение друзей в Steam группу
- ✅ Фарм часов в играх
- ✅ Массовая рассылка сообщений в чат (мин. задержка 8 сек)
- ✅ Отправка комментариев на профили друзей (мин. задержка 7 сек)
- ✅ Управление несколькими аккаунтами одновременно

### Управление операциями
- ⏸️ Пауза/Продолжить для всех операций
- ⏹️ Полная остановка операций
- 📊 Прогресс-бары в реальном времени

### Оптимизация производительности
- 🎮 Автоматическое снижение нагрузки при игре
- 📉 Адаптивные интервалы обновления UI
- 🗑️ Оптимизированное логирование
- 💾 Эффективное управление памятью

## Установка

```bash
npm install
```

## Запуск

```bash
npm run electron
```

## Использование

1. Нажмите "Добавить аккаунт"
2. Введите Steam логин и пароль
3. Нажмите "Войти"
4. Если требуется Steam Guard код - введите его в появившемся окне

## Производительность

Приложение автоматически определяет когда вы находитесь в игре и снижает нагрузку:

### Режимы производительности
- **Normal** - полное функционирование (по умолчанию)
- **Low** - сниженная частота обновлений
- **Minimal** - минимальная нагрузка при игре

### Что оптимизируется
- Частота обновления UI (1с → 3с → 10с)
- Логирование (отключение debug логов)
- Проверки памяти (5мин → 10мин → 15мин)
- Отправка некритичных событий

## Настройки задержек

- **Приём друзей**: минимум 7 секунд
- **Отправка сообщений**: минимум 10 секунд
- **Рассылка в чат**: минимум 8 секунд
- **Комментарии на профили**: минимум 7 секунд

## Логи

Логи записываются в файл `bot.log` в папке данных приложения.
В режиме игры debug логи отключаются для снижения нагрузки.

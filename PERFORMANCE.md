# Оптимизация производительности

## Автоматическая адаптация

Приложение автоматически определяет когда пользователь находится в игре и снижает нагрузку на систему.

## Режимы производительности

### Normal (обычный)
- **Когда активен**: По умолчанию, когда пользователь не в игре
- **UI обновления**: Каждую 1 секунду
- **Проверки памяти**: Каждые 5 минут
- **Логирование**: Полное (info, warn, error, success, debug)

### Low (сниженный)
- **Когда активен**: При средней нагрузке системы
- **UI обновления**: Каждые 3 секунды
- **Проверки памяти**: Каждые 10 минут
- **Логирование**: Без debug логов

### Minimal (минимальный)
- **Когда активен**: Когда пользователь находится в игре
- **UI обновления**: Каждые 10 секунд
- **Проверки памяти**: Каждые 15 минут
- **Логирование**: Только error и success
- **Консольный вывод**: Отключен (кроме ошибок)

## Что оптимизируется

### 1. UI обновления
```javascript
const UI_UPDATE_INTERVAL = {
  normal: 1000,    // 1 секунда
  low: 3000,       // 3 секунды
  minimal: 10000   // 10 секунд
};
```

### 2. Логирование
- В режиме **minimal** debug логи полностью отключаются
- Консольный вывод отключен (кроме критических ошибок)
- Запись в файл продолжается для всех уровней

### 3. Проверки памяти
- Интервал автоматической проверки памяти адаптируется
- Garbage collection вызывается реже в режиме minimal

### 4. Отправка событий
- Некритичные события не отправляются в режиме minimal
- Критические обновления (статус аккаунта) всегда отправляются
- Progress updates throttled согласно режиму

## Как определяется режим

Приложение проверяет статус каждого активного бота каждые 5 секунд:

```javascript
function checkIfUserInGame() {
  for (const accountId in activeBots) {
    const bot = activeBots[accountId];
    if (bot.user.personaStates) {
      const ownState = bot.user.personaStates[bot.user.steamID.toString()];
      if (ownState && ownState.game_name) {
        return true; // Пользователь в игре
      }
    }
  }
  return false;
}
```

## Ручное управление

Вы можете вручную установить режим производительности через API:

```javascript
// Получить текущий режим
const mode = await window.steamBot.getPerformanceMode();
// { mode: 'normal', isUserInGame: false, activeBots: 2 }

// Установить режим
await window.steamBot.setPerformanceMode('minimal');
```

## Уведомления о смене режима

Приложение отправляет уведомление при автоматической смене режима:

```javascript
window.steamBot.onPerformanceModeChanged((data) => {
  console.log('Режим изменен:', data.mode);
});
```

## Рекомендации

### Для разработчиков
- Используйте `sendToRenderer(channel, data, forceUpdate)` для критичных обновлений
- Параметр `forceUpdate = true` обходит throttling
- Избегайте частых обновлений UI в циклах

### Для пользователей
- Приложение автоматически оптимизируется при игре
- Ручная смена режима не требуется
- Если производительность низкая - проверьте количество активных ботов

## Производительность

### До оптимизации
- CPU: 5-10% в режиме простоя
- RAM: 200-300 MB
- UI updates: 1 в секунду на каждый аккаунт

### После оптимизации
- CPU: 1-2% в режиме minimal
- RAM: 150-200 MB
- UI updates: 1 в 10 секунд в режиме minimal

## Известные ограничения

- Определение игры работает только через Steam API
- Если бот не авторизован, режим не определяется
- Ручная смена режима перезаписывается автоматической через 5 секунд

# Инструкция по замене иконки приложения

## 📋 Что нужно сделать

### Шаг 1: Подготовьте иконку

Вам нужна иконка в следующих форматах:

#### Для Windows (.ico)
- **Размер**: 256x256 пикселей (или больше)
- **Формат**: ICO (содержит несколько размеров: 16x16, 32x32, 48x48, 64x64, 128x128, 256x256)
- **Имя файла**: `icon.ico`
- **Расположение**: в корне проекта

#### Для macOS (.icns)
- **Размер**: 1024x1024 пикселей
- **Формат**: ICNS
- **Имя файла**: `icon.icns`
- **Расположение**: в корне проекта

#### Для Linux (.png)
- **Размер**: 512x512 пикселей
- **Формат**: PNG
- **Имя файла**: `icon.png`
- **Расположение**: в корне проекта

#### Для трея (tray-icon.png)
- **Размер**: 32x32 или 64x64 пикселей
- **Формат**: PNG с прозрачностью
- **Имя файла**: `tray-icon.png`
- **Расположение**: в корне проекта

## 🔧 Как установить иконку

### Для Windows (icon.ico)

1. Скачайте или создайте PNG иконку 256x256 или больше
2. Конвертируйте в ICO формат (см. выше)
3. Поместите файл `icon.ico` в корень проекта
4. Файл уже настроен в `package.json`:
   ```json
   "win": {
     "target": ["portable"],
     "icon": "icon.ico"
   }
   ```

### Для трея (tray-icon.png)

1. Создайте или скачайте PNG иконку 32x32 или 64x64
2. Поместите файл `tray-icon.png` в корень проекта
3. Файл уже настроен в `electron.cjs`:
   ```javascript
   icon: path.join(__dirname, "tray-icon.png")
   ```

### Для macOS (icon.icns)

1. Скачайте или создайте PNG иконку 1024x1024
2. Конвертируйте в ICNS формат
3. Поместите файл `icon.icns` в корень проекта
4. Соберите для macOS:
   ```bash
   npm run build-mac
   ```

### Для Linux (icon.png)

1. Скачайте или создайте PNG иконку 512x512
2. Поместите файл `icon.png` в корень проекта
3. Соберите для Linux:
   ```bash
   npm run build-linux
   ```

## 🎯 Рекомендации по дизайну

### Что должно быть на иконке:
- ✅ Простой, узнаваемый дизайн
- ✅ Яркие цвета (синий, голубой)
- ✅ Читаемость в маленьком размере (16x16)
- ✅ Тематика: робот, автоматизация, Steam

### Что НЕ должно быть:
- ❌ Мелкие детали (не видны в 16x16)
- ❌ Текст (не читается в маленьком размере)
- ❌ Слишком много цветов
- ❌ Сложные градиенты

### Примеры хороших иконок:
- Робот с голубыми глазами
- Шестеренка с символом Steam
- Молния (символ автоматизации)
- Голова робота в стиле минимализм

## 🐛 Решение проблем

### Проблема: Иконка не отображается
**Решение**:
1. Проверьте имя файла (должно быть точно `icon.ico` или `tray-icon.png`)
2. Проверьте расположение файла (должен быть в корне проекта)
3. Пересоберите приложение: `npm run build-win`
4. Очистите кэш Windows:
   ```bash
   ie4uinit.exe -show
   ```

### Проблема: Иконка размытая
**Решение**:
1. Используйте исходное изображение большего размера (512x512 или больше)
2. Конвертируйте в ICO с несколькими размерами
3. Убедитесь что ICO содержит размер 256x256

### Проблема: Иконка не в трее
**Решение**:
1. Проверьте файл `tray-icon.png` (32x32 или 64x64)
2. Перезапустите приложение
3. Проверьте код в `electron.cjs`:
   ```javascript
   tray = new Tray(path.join(__dirname, 'tray-icon.png'));
   ```
